# S&P 500 Financial Analysis

## Overview
Analysis of 505 S&P 500 companies using Python, Pandas, and Matplotlib.

## Key Findings
- Consumer Discretionary dominates the S&P 500 with 84 companies
- Apple leads all companies in Market Capitalization
- Energy and IT sectors have highest P/E ratios
- Telecom offers highest dividend yield at 7.57%
- Financials sector appears potentially undervalued

## Tools Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebooks

## Dataset
S&P 500 company financials from Kaggle
